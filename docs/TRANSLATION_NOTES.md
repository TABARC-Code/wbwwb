# Translation notes

AI was used to draft and revise parts of the German, Spanish, Turkish,
Portuguese and Persian text. That needs saying plainly. It is useful provenance,
not a tiny confession hidden behind the sofa.

I used English as the canonical source because I can maintain it without
guessing. The locale audit proves that translated keys exist, catalogues have
the expected shape, and missing entries fall back safely. It does **not** prove
that a joke lands, that a headline sounds natural, or that a regional phrase
hasn't wandered into the wrong country wearing somebody else's shoes.

I made a judgement call here. A playable rough translation was more useful than
leaving every new system English-only, provided the uncertainty stayed visible.
That decision is not neccessarily the final one.

If you are a native or fluent speaker, fixes are welcome. Please keep the intent
of each line as well as its literal meaning. The middle television should sound
dry and procedural. The side televisions should sound manipulative, heated and
slightly too certain. A grammatically perfect line with the wrong editorial
temperature is still the wrong line.

Useful corrections include:

- grammar, spelling and punctuation;
- idioms that sound translated rather than spoken;
- regional wording that is confusing outside one country;
- headlines that lose the contrast between neutral reporting and agitation;
- text that overruns the television display;
- cultural assumptions that simply do not travel.

When changing a locale, run `npm run check`. Then look at it in the actual game.
The audit catches broken keys. It cannot catch bad rhythm, cramped lettering or
a joke that has died quietly on the journey.

This file is written in the first person because somebody made these choices.
“The system decided” would be a wonderfully convenient little ghost.
