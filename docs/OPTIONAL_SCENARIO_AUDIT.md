# Optional-scenario actor audit

7 October 2026. Standalone branch: `codex/core-rebuild-fork-audit`.
Baseline: `830bc9e95ba3e838aae1ea3f51c4902857b37245`.

## Reproduced faults

Cricket calming could replace the scripted nervous character with a normal
person, leaving the current act waiting for a character that no longer existed.
It could also remove the only angry character able to propagate the next story
beat. The influence laboratory could turn named actors, including the hat wearer,
into generic angry people before their photograph-dependent transitions.

Three focused regression tests failed on the baseline. They now pass:

- In scenes with a director, cricket calming preserves nervous actors and the
  last angry actor. It still converts surplus angry people. Director-free
  sandbox scenes can still calm nervous people.
- Influence class changes now start with ordinary crowd members, or continue
  with people previously generated by the influence model. Authored special
  actors keep their classes, while their influence state can still change.
- Model-generated nervous people can subsequently become angry. This prevents
  cast protection from accidentally disabling the laboratory's transformations.

This batch contains two production fixes. It was audited after both; no extra
changes were added simply to reach four.

## Validation and scope

Local syntax, locale and asset checks pass. All 96 Node tests, 309 seeded model
simulations and the existing virtual playtest pass. The new browser scenario
fixtures load the real optional modes, exercise actual actor constructors and
world replacements, and render the result. They are targeted integration tests,
not complete optional-scenario playthroughs.

The ordinary authored walkthrough remains a separate regression gate covering
four seasonal/strategy runs through the final menu. Full optional-scenario
end-to-end coverage remains open: the influence laboratory can create additional
nervous and angry crowd members, so protecting named roles alone does not prove
that every possible laboratory crowd can complete every original act. No claim
of exhaustive optional-mode progression is made here.

No changes were made to money, trust, spread coefficients, translations or the
main/master branch. Physical-device readability, human pacing, cross-browser
coverage and clean packaged installation remain outside this audit.
